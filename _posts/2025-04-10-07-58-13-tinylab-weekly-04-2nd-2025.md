## Linux 内核最新消息

Linux 6.15 合并窗口已经结束，Linus Torvalds 本周发布了 6.15-rc1。这个版本的提交数量和更改的行数都很大。统计数据看起来也还算正常。值得一提的一些关键亮点包括：

- IO_uring 网络零拷贝接收支持。

- Bcachefs 文件系统现在将其磁盘格式视为 “软冻结” 状态，但保留将来更新的可能性。

- 针对 Zstd 1.5.7 更新树内 Zstd 压缩代码，以获得更好的性能和其他改进。

- 非常早期的 NOVA 核心驱动程序。

- 支持 AMD Versal NET SoC。

- AMD INVLPGB 已被合并，以便与较新的 AMD 处理器进行很好的优化，以实现广播 TLB 失效。

- 在 AMD Zen 5 和其他 Intel/AMD CPU 上实现更快的 AES-CTR 加密性能。

- 新的 AMD 图形硬件支持。

- 新的 “hugetlb_alloc_threads” 引导选项，可以帮助加快内核引导时间。

- Perf 获得了新的延迟分析功能。

- 支持大于内核页面大小的块大小

- 新的 Apple Z2 触摸屏/触摸条驱动程序以及 Apple Touch Bar DRM 显示驱动程序代码。

- 为支持大型原子写入（atomic write）所作准备工作。

- 新的 FWCTL 子系统。

Linux 6.15 稳定版应该会在 5 月底或 6 月初左右发布。

此外，Greg Kroah-Hartman 在本周伊还发布了 Linux 6.14.1，包含两周前 Linux 6.14 代码库之上的初始修复集合，带来了一些新的设备 ID 和硬件的补丁。Linux 6.14.1 中的更改包括针对 ASUS UM5606KA 上的低音音频问题、支持 HP 笔记本电脑 15s-du3xxx 设备上的静音 LED、添加了更多 TTY 串行 8250 驱动程序设备 ID，以及一些常规代码修复。

此外，Greg Kroah-Hartman 还发布了 Linux 6.13.10、Linux 6.12.22 LTS、Linux 6.6.86 LTS 和 Linux 6.1.133 LTS 内核。

## Linux 6.15 中针对 RISC-V 增加了对 BFloat16 “BF16” 指令的支持

> Merged on Friday for the nearly-over Linux 6.15 merge window were the RISC-V CPU architecture updates for this next kernel release.

上周五，在 Linux 6.15 合并窗口期间，合并了新内核版本中针对 RISC-V CPU 架构的更新。其中包括：

针对 RISC-V 的构建改进，这要归功于围绕 RISC-V 重构了 Kconfig 构建系统选项，方便选择子架构功能。

此外，针对 RISC-V，Linux 6.15 内核还支持构建可重定位的非 MMU 内核，支持巨大的 PFNMAPS 以提高 TLB 利用率，支持运行时常量，支持新的 RISC-V 指令以及各种修复。

6.15中的 RISC-V 增加了对许多较新指令的支持，包括 bfloat16、Zicbom、Zaamo、Zalrsc、Zicntr 和 Zihpm。RISC-V 终于准备好支持其 BFloat16 精度浮点 ISA。BF16 扩展已批准用于 RISC-V 规范，正为 Linux 内核做好准备。

新闻出处，“RISC-V With Linux 6.15 Adds Support For BFloat16 "BF16" Instructions”: <https://www.phoronix.com/news/Linux-6.15-RISC-V>。

**关键词**: Linux, RISC-V

## Linux 6.15 中为 LoongArch 架构新增更多功能

> The Chinese LoongArch CPU architecture will enjoy slightly better support with the upcoming Linux 6.15 kernel.

来自中国的 LoongArch CPU 架构在 Linux 6.15 内核中将得到更好的支持。

LoongArch 的更改已于上周末发布，主要包括以下内容：

- 增加对 objtool 的跳转表支持;
- 始终选择 `HAVE_VIRT_CPU_ACCOUNTING_GEN`;
- 启用 UBSAN（Undefined Behavior Sanitizer）;
- 增加 `MAX_IO_PICS` 至 8;
- 增加 `ARCH_DMA_MINALIGN` 至 16;
- 修复和改进 BPF JIT;
- 修复和改进 vDSO 实现;
- 更新默认配置文件;
- 一些错误修复和其他小改动。

新闻出处，“LoongArch Enables A Few More Features With Linux 6.15”: <https://www.phoronix.com/news/Linux-6.15-LoongArch>。

**关键词**: Linux, LoongArch

## Debian APT 3.0稳定版发布，带有新的软件包求解器和改进的文本用户界面

> All of the FUSE updates have been sent in for the in-development Linux 6.15 kernel for supporting file-systems in user-space.

经过了一个有趣的开发周期后, APT 3.0 作为稳定版本正式发布。APT 3.0 的发布是对已故的 Steve Langasek 的致敬，多年来他为 Debian 和 Ubuntu 做出了许多贡献。

APT 3.0 稳定版先于 Ubuntu 25.04 和 Debian 13.0 版本之前发布，而 Debian 13 预计会在今年晚些时候发布。事实证明，APT 3.0 是这个包管理工具的一个非常重要的更新，对于习惯使用文本用户界面 （Text User Iinterface） 用户体验来说会有相当不错的改进。

APT 3.0 是继 APT 2.9 之后发布的一个新的稳定版本。这个稳定版本带来了新的包求解器，对于 Linux 命令行用户来说，非常突出的是具有颜色、列式显示和其他改进的新 UI。大家一直很喜欢 APT 2.9 版本所带来的精致的文本用户界面，现在也被 APT 3.0 版本所继承，而且它比以前的版本更加精致，看起棒极了。期待 APT 3.0 能够被 Debian/Ubuntu 的 Linux 发行版所采用。

新闻出处，“Debian APT 3.0 Stable Released With New Package Solver & Refined Text UI”: <https://www.phoronix.com/news/Debian-APT-3.0-Released>。

**关键词**: Debian, APT

## Ubuntu 新增对低成本 RISC-V 开发板 OrangePi RV2 的支持

> Canonical announced today they have released Ubuntu developer images for the Orange Pi RV2, a new RISC-V single board computer that is low-cost with the SBC featuring 8GB of RAM costing just $64 USD.

Canonical 于本周二（4 月 8 日）宣布，他们已经发布了适用于 Orange Pi RV2 的 Ubuntu 开发版镜像，这是一款新的 RISC-V 单板计算机，成本低廉，SBC 具有 8GB RAM，成本仅为 64 美元。

Orange Pi RV2 是 Canonical 移植的最新 RISC-V 开发板，可运行 Ubuntu Linux。Orange Pi RV2 使用 KY-X1 八核 SoC，支持 RISC-V 的矢量扩展和 RVA22 扩展。此外，还有一个 AI 加速器，尽管额定功率仅为 2 TOPS。

这款 8 核 RISC-V SBC 配备 2GB、4GB 或 8GB LPDDR4X 内存。板上还有两个 M.2 M-key 插槽、WiFi 和蓝牙，以及双千兆以太网端口。有一个 HDMI 输出，适合那些想要驱动显示器的人。

有关这款低成本 RISC-V 单板计算机本身的详细信息，请访问 OrangePi.org <http://www.orangepi.org/html/hardWare/computerAndMicrocontrollers/details/Orange-Pi-RV2.html>。

高端 8GB 型号的零售价约为 64 美元，与许多其他 RISC-V 板相比，它的价格非常有吸引力。

新闻出处，“Ubuntu Adds Support For A New Low-Cost RISC-V Board: The OrangePi RV2 8GB For ~$64”: <https://www.phoronix.com/news/Ubuntu-Linux-On-OrangePi-RV2>。

**关键词**: Linux, Ubuntu, OrangePi RV2
