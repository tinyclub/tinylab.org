## Linux 6.16 中将对 RISC-V 支持一些新的 SiFive 供应商扩展

> Queued within the development tree for the RISC-V processor code for the Linux kernel is supporting several new vendor-specific ISA extensions for SiFive RISC-V CPU cores.

在 RISC-V 开发仓库中排队的 Linux 内核代码支持了 SiFive 的 RISC-V CPU 核所提供的几个新的供应商特定的 ISA 扩展。

这部分修改于上周，在 Linux 6.16 发布之前进入了 riscv/linux.git 的 “for-next” 分支，这些补丁为 RISC-V 启用了一些新的 SiFive 供应商扩展。将为 Linux 6.16 引入四个 SiFive 供应商扩展：它们是xsfvqmaccdod、xsfvqmaccqoq、xsfvfnrclipxfqf 和 xsfvfwmaccqqqq。

- xsfvqmaccdod：用于 SiFive Int8 矩阵乘法扩展。

- xsfvqmaccqoq：用于 SiFive Int8 矩阵乘法扩展。

- xsfvfnrclipxfqf 用于 SiFive FP32-to-int8 Ranged Clip 指令。

- xsfvfwmaccqq 是 SiFive 的矩阵乘法累加指令。

这些新的 SiFive 供应商特定的 ISA 扩展将出现在他们即将推出的一些 RISC-V 内核设计中。在 Linux 6.16 中可以找到对这些核心的支持。编译器将利用这些 SiFive 扩展，包括 GNU/GCC 和 LLVM 工具链在内都将围绕这些扩展实现更多的功能。

新闻出处，“Support For New RISC-V SiFive Vendor Extensions On The Way For Linux 6.16”: <https://www.phoronix.com/news/Linux-6.16-New-SiFive-RISC-ISA>。

## DeepComputing 推出第二代 DC-ROMA RISC-V 主板

> The past year we've been looking forward to a RISC-V motherboard option coming to the Framework Laptop 13 via Framework's partnership with DeepComputing. There was early access in late 2024 while this week DeepComputing has formally announced the DC-ROMA RISC-V AI PC Mainboard II now available at $349 USD.

在过去的一年里，我们一直期待着通过 Framework 与 DeepComputing 的合作，为 Framework Laptop 13 提供更多 RISC-V 主板选项。2024 年底我们已经有过抢先体验，而本周 DeepComputing 正式宣布推出第二代 DC-ROMA RISC-V AI PC 主板，售价 349 美元。

DeepComputing 的 DC-ROMA RISC-V AI PC 主板 II 采用 ESWIN 7702X SoC 和 SiFive P550 RISC-V 内核。这款适用于 Framework Laptop 13 的主板提供八个高达 2.0GHz 的 RISC-V 内核、一个 40 TOPS NPU、PowerVR Imagination 显卡、32GB 内存、SSD 或 eMMC/SSF/TF 卡，默认配备 Ubuntu 24.04 LTS。这款新的 “主板 II” 是对由 JH7110 SoC 驱动的原始 DC-ROMA RISC-V 主板的改进。

Framework 笔记本电脑的 DC-ROMA 主板 II 的基本包和 32GB RAM 的价格为 349 美元，不含其他存储设备扩展。以此基本包为基础，添加额外的附加，价格也会随之上涨，或者直接购买 Framework Laptop 13 整机箱版本。

那些想了解更多关于 Framework 笔记本电脑的 RISC-V 主板选项的人可以在 <https://deepcomputing.io/product/dc-roma-risc-v-ai-pc/> 了解更多信息。

新闻出处，“DeepComputing's DC-ROMA RISC-V Mainboard II For Framework Laptop Launches For $349”: <https://www.phoronix.com/news/DC-ROMA-RISC-V-Framework-Launch>。

## AMD 开始为 Zen 6 CPU 准备 Linux 内核

> The first AMD Zen 6 patch for the Linux kernel has been queued up for submission soon to the mainline kernel.

Linux 内核的第一个 AMD Zen 6 补丁已排队等待很快提交给主线内核。第一个补丁本身并不令人兴奋，但正在启动解锁其他 AMD Zen 6 内核补丁的过程，以便在预计于 2026 年首次亮相的 AMD Zen 6 处理器之前上游内核已经可以支持它。

第一个补丁只是添加了 “X86_FEATURE_ZEN6” 的合成功能标志，如果打算检查 Zen 6 CPU 内核，其他内核补丁可以依赖此功能标志启用对 Zen 6 系列的支持。

此 X86_FEATURE_ZEN6 补丁确实确认 Zen 6 CPU 将像 Zen 1 处理器一样出现在 Family 26Ah（Family 5）中。Zen 6 处理器是 1Ah 系列和型号 ID，从 0x50 到 0x5f、0x90 到 0xaf 和 0xc0 到 0xcf。

补丁将排队到 tip/tip.git 的 “x86/urgent” 分支中。它很可能作为当前 Linux 6.15 周期的 “fixes” 的一部分提交，而不是等待几周后打开 Linux 6.16 合并窗口。

因此，虽然这个 X86_FEATURE_ZEN6 补丁本身并不是特别令人兴奋，但它现在为进一步的 AMD Zen 6 Linux 内核补丁打开了大门。请继续关注明年下一代 Ryzen 和 EPYC 处理器上即将推出的更多 Linux 变化，这肯定会非常令人兴奋。

新闻出处，“AMD Begins Process Of Preparing The Linux Kernel For Zen 6 CPUs”: <https://www.phoronix.com/news/AMD-Zen-6-Linux-Kernel-Start>。

**关键词**: Linux, AMD, Zen 6

## GSoC 2025 项目启动

> This week Google announced all of the accepted projects for this year's Google Summer of Code (GSoC). There are 1,272 accepted students/projects this year for student developers working on various interesting open-source efforts over the summer.

本周，Google 宣布了所有今年 Google Summer of Code （GSoC） 接受的项目。今年有 1,272 名被录取的学生/项目，供学生开发人员在暑假期间从事各种有趣的开源工作。

在浏览 GSoC 2025 的所有已接受项目时，以下是我发现 Google 将通过 Google Summer of Code 资助的一些最有趣的工作。

Fedora 已经安排了一些项目来创建一个服务，以便更轻松地将新项目导入 Fedora。还有一个“Explain My Logs”Fedora 项目，用于 AI 驱动的自然语言日志分析器，用于 DevOps 和基础设施调试。同样，openSUSE 项目也有一个 GSoC 2025 计划，为 openSUSE/OBS 提供日志检测，并为验收测试提供 AI 驱动的测试选择。

在 GNOME 方面，将在 GNOME Papers（Evince Document Viewer）中寻求后端隔离，以获得更好的安全性和稳定性。GNOME 还将看到为 Sysprof 添加 eBPF 分析功能的工作。

在 KDE 方面，有一些项目将 ISO Image Writer GUI 移植到 Kirigami，增强 Kdenlive 视频编辑器，改进 KWin 中的游戏控制器支持，并为新的 “KDE Linux”作系统项目创建网站。

在 Chrome 项目下，包括开发 Fwupd 插件以处理触摸控制器的触摸固件更新、WebGPU Texel 缓冲区、增强 Chrome 扩展 API、对标签页组的第三方主题支持、改进 Chromium Web 音频测试以及开发虚拟打印机应用程序的项目。

与此同时，GitLab 开源项目将致力于通过高级源代码控制功能增强其 Web IDE。

Neovim 编辑器将看到在远程 SSH 编辑支持和增强 AI 原语方面的工作。

LLVM 项目正在寻求 ClangIR 上游、改进未定义行为清理器、LLVM libc 中的 BFloat16 支持等。

与 Google Summer of Code 合作的 Debian 项目希望看到在增强其 Salsa 持续集成 （CI）、打包 LLM 推理库、更好地支持 Debian Linux 上的 AMD ROCm 软件包以及恢复 Debian 的 Raspberry Pi 构建方面的工作取得进展。

在 Linux 世界之外，NetBSD 将致力于异步 I/O 框架，并利用 Bubblewrap 在此 BSD 上进行沙箱处理。与此同时，FreeBSD 正在寻求对 QEMU 的 VMM 加速器支持，QEMU 是 FreeBSD 的完整磁盘管理工具，并加快了 FreeBSD 的启动过程。

Rust 项目正在努力对其 libc crate 进行现代化改造，添加安全契约，并使用 rustc_codegen_gcc GCC Rust 代码提升 rustc。Rustup 也希望在今年夏天同时进行。

通过 FFmpeg 项目，计划用于基于 ProRes Vulkan 的视频编码器和解码器。FFmpeg 还希望看到这个开源多媒体库的 WHIP （WebRTC-HTTP Ingestion Protocol） 实现。

在 Linux 基金会的保护伞下，正在完成 GNOME 的新打印架构，发布 patch-hub 1.0 版本，libcups2/libcups3 的 Rust 绑定，以及其他打印工作。

GIMP 图像编辑器希望看到一个通过 GSoC 2025 开发的扩展网站。

在今年的 Google Summer of Code 中，LibreOffice 的目标是实现 Python 代码自动完成、Rust UNO 语言绑定以及此开源办公套件的其他增强功能。

最后，VideoLAN 项目希望看到 Wayland API 添加到 libVLC 库中。

可以访问 <https://summerofcode.withgoogle.com/> 了解有关 GSoC 2025 项目的更多信息。

新闻出处：“GSoC 2025 Projects: AI-Powered Log Analyzer For Fedora, Better AMD ROCm On Debian”: <https://www.phoronix.com/news/GSoC-2025-Projects>。
